Data Preparation and Pre-processingOptical & Radar Data Acquisition: Acquire dense time-series imagery from Sentinel-1 (C-band SAR in VV and VH polarizations) and Sentinel-2 optical datasets covering the complete crop growth cycle.   SAR Preprocessing Workflow: Apply precise orbit file corrections, thermal noise removal, border noise removal, radiometric calibration to $\sigma^{0}$ (sigma nought) backscatter coefficients, and speckle filtering (such as multi-temporal or median filtering) to preserve spatial boundaries while reducing noise.   Terrain Correction: Perform geometric terrain correction using a Digital Elevation Model (DEM) via bilinear interpolation to eliminate topographic distortions.   2. Feature Extraction and Index CalculationOptical Indices: Compute vegetation indices like NDVI and Enhanced Vegetation Index (EVI/EVI-2) to capture green biomass and photosynthetic activity.   Dual-Pol SAR Indices & Ratios: Derive radar vegetation and polarization indices—such as the VH/VV ratio, Normalized Ratio Procedure between Bands (NRPB), Dual-Pol Diagonal Distance (DPDD), Inverse Dual-Pol Diagonal Distance (IDPDD), and Vertical Dual De-Polarization Index (VDDPI)—to characterize physical scattering and structural crop changes.   Texture Measures: Calculate Grey Level Co-occurrence Matrix (GLCM) texture features to account for structural spatial variations.   3. Training Sample Delineation and Class SeparabilityGround Truth Collection: Gather reference polygons and field survey data (such as BBCH phenological stages or crop calendars) to define training and validation regions of interest (ROIs).   Separability Analysis: Evaluate class separability using statistical distribution checks, scatter plots, and Euclidean distance matrices to minimize inter-class overlapping (e.g., between cereals, summer crops, and forests).   4. Model Architecture & ImplementationClassifier Selection: Implement non-parametric machine learning classifiers—primarily Random Forest (RF) and Support Vector Machine (SVM)—which handle complex multi-dimensional feature spaces effectively.   Phenological or Temporal Modeling: Group or stack features across temporal intervals to capture crop-specific growth trajectories, or implement automated temporal model matching (such as Spectral Similarity Value [SSV] or Phenological Sequence Patterns [PSP]).   5. Version Control and Scripting (GitHub)Organize the entire end-to-end preprocessing, feature extraction, and classification code into modular scripts.Push the repository to GitHub to ensure reproducibility, version tracking, and collaborative workflow management.
